YAGPDB Community

Community resources and shared configuration for the YAGPDB Community organization.

About

YAGPDB Community is a community-driven collection of YAGPDB custom commands for Discord servers.

This repository contains shared GitHub community files and organization-wide resources.

Community Repositories

yagpdb-commands

The main repository for community-submitted YAGPDB custom commands.

Commands are organized into categories such as:

Moderation
Utility
Fun
Games
All contributions are reviewed before being merged into the main branch.

Contributing

Want to contribute a YAGPDB custom command?

Visit the main repository and read its "CONTRIBUTING.md" for submission guidelines.

Organization

This repository belongs to the YAGPDB-Community GitHub organization.

The goal is to build an open community collection of useful, fun, and creative YAGPDB custom commands.
