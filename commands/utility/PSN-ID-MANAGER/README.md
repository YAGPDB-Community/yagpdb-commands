# 🎮 YAGPDB PSN ID Manager

A feature-rich **YAGPDB Custom Command** for Discord servers that enables members to register, display, and manage their PlayStation Network (PSN) IDs. Includes full administrative override support.

## ✨ Features
- **User Self-Management:** Members can add, update, or remove their own PSN ID.
- **Admin Overrides:** Admins can assign or remove PSN IDs for any member via mentions.
- **Embed Display:** Clean, formatted Discord Embed list of all registered players.
- **Database Backed:** Utilizes YAGPDB's internal key-value database.

## ⚙️ YAGPDB Configuration

1. Go to your **YAGPDB Control Panel** -> **Tools & Utilities** -> **Custom Commands**.
2. Click **Create new Custom Command**.
3. Configure the trigger settings:
   - **Trigger Type:** `Command`
   - **Trigger:** `psn`
