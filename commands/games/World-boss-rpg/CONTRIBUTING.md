🤝 Contributing

Thank you for your interest in contributing to the World Boss System!

Whether you're reporting a bug, suggesting a new feature, improving the documentation, or submitting code improvements, your contributions are greatly appreciated.

---

💡 Ways to Contribute

You can help improve this project by:

- 🐛 Reporting bugs or unexpected behavior.
- 💭 Suggesting new features or gameplay ideas.
- 📖 Improving the documentation.
- ⚖️ Helping balance combat, items, and rewards.
- 🧹 Optimizing or refactoring existing commands.
- 🌍 Translating the documentation into other languages.

---

📝 Before You Contribute

Before opening an Issue or Pull Request, please:

- Check if the issue or suggestion has already been reported.
- Make sure your contribution fits the project's scope.
- Keep changes focused and easy to review.

---

🛠️ Pull Requests

When submitting a Pull Request:

1. Clearly describe what has changed.
2. Explain why the change is needed.
3. Test your changes before submitting.
4. Keep commits clean and descriptive.

Example commit messages:

- "Add new healing item"
- "Fix leaderboard sorting"
- "Improve boss attack calculation"
- "Update installation guide"

---

🐞 Reporting Bugs

When reporting a bug, please include:

- The command where the issue occurred.
- A description of what happened.
- The expected behavior.
- Any error messages from YAGPDB.
- Steps to reproduce the issue.

The more information you provide, the easier it will be to fix the problem.

---

💬 Feature Requests

Have an idea to improve the World Boss System?

Open an Issue and include:

- A clear description of the feature.
- Why it would improve the project.
- Any implementation ideas, if applicable.

Constructive suggestions are always welcome.

---

📜 Code Style

Please keep the code:

- Clean and well organized.
- Easy to understand.
- Consistent with the existing project structure.
- Properly commented where necessary.

Avoid unnecessary complexity whenever possible.

---

❤️ Thank You

Every contribution—big or small—helps make the World Boss System better for everyone.

Thank you for taking the time to contribute and support the project!
