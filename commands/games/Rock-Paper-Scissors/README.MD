Rock Paper Scissors for YAGPDB

A simple Rock • Paper • Scissors game built with YAGPDB Custom Commands for Discord.

Features

- 🎮 Easy-to-use command ("!rps")
- 🪨📄✂️ Random bot choice
- 🏆 Win, Lose, or Tie results
- ✨ Clean embed responses
- ⚡ No database required
- 🔧 Easy to customize and expand

Perfect for Discord servers looking for a lightweight and fun mini-game powered entirely by YAGPDB.
