🎮 Guess The Number - YAGPDB Custom Game

A complete Guess The Number mini-game built for YAGPDB Custom Commands.

Players must guess a randomly generated number while the game manages difficulty, attempts, hints and progress tracking through an interactive Discord experience.

✨ Features

🎲 Random Difficulty System

The game randomly selects a difficulty:
🟢 Easy: 1 - 50
🟡 Medium: 1 - 100
🔴 Hard: 1 - 250
❤️ Attempts System

Each difficulty has a different number of attempts.
Players must find the number before running out of tries.
📈 Higher / Lower Hints

The game provides hints after every incorrect guess:
📈 The number is higher
📉 The number is lower
📝 Guess History

Previous guesses are saved and displayed during the game.
Players can track their progress.
