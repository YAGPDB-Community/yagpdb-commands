# Contributing to YAGPDB Community

Thank you for contributing to the YAGPDB Community!

This project is a community-driven collection of YAGPDB custom commands.

## How to submit a command

1. Fork this repository.
2. Create a new branch.
3. Add your command to the appropriate category.
4. Include documentation for the command.
5. Open a Pull Request.
6. Wait for the maintainers to review your submission.

## Command requirements

Every submitted command should include:

- Command name
- Description
- Required permissions
- Required database keys
- Dependencies, if any
- Installation instructions
- Usage examples

## Security

Do not submit:

- Passwords
- API keys
- Discord bot tokens
- Webhook secrets
- Personal information
- Malicious code
- Commands designed to spam or abuse Discord servers

Never include credentials or private server information in a Pull Request.

## Review process

Every submission is reviewed before it becomes part of the official library.

Maintainers may:

- Approve the Pull Request
- Request changes
- Close the Pull Request

A Pull Request is not considered an approved command until it has been merged into `main`.

## Testing

Test your command in a test Discord server before submitting it.

Make sure that all required permissions, database keys and dependencies are documented.

## Ownership

By submitting code, you confirm that you have the right to share the code with this project.

Do not submit code copied from another project unless its license permits redistribution.
